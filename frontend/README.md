# Shoply Frontend

Bu qovluq ayrıca, frameworksüz HTML/CSS/JavaScript frontend-dir.

1. Backend-i `mvn spring-boot:run` ilə başladın.
2. `frontend` qovluğunda serveri başladın:

   ```powershell
   node server.js
   ```

3. Brauzerdə `http://localhost:5500` açın.

Frontend standart olaraq backend-in `http://localhost:8080` ünvanından istifadə edir.
